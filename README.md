### 🗣 Voice Bot for Public Service Center (MFC) — Production Deployment

**Stack:** Python, aiogram, REST API, Webhooks, TTS (Text-to-Speech)

* Developed and deployed a **voice notification bot** for a government service center (MFC) to broadcast announcements in the waiting hall
* Integrated with **Telegram** and **VK** messengers via **webhooks** using **aiogram**
* Implemented **REST API (GET/POST)** between the admin interface and the playback system
* Configured **TTS (text-to-speech)** synthesis for converting text messages into voice announcements
* Solved a real business need with minimal budget, reducing manual workload for administrators

**Result:** Automated mass notification system used daily by 20+ employees.
