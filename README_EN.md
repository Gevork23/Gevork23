## 🚀 Key Projects

### 🗣 [Voice Bot for MFC (Multifunctional Center)](https://github.com/Gevork23/max_bot) — Production Solution

**Stack:** Python, aiogram, REST API, Webhooks, TTS (Text-to-Speech)

- Developed and deployed a **voice notification bot** for a government service center to broadcast announcements in waiting areas
- Integrated with **Telegram** and **VK** messengers via **webhooks** using **aiogram**
- Implemented **REST API (GET/POST)** between admin interface and playback system
- Configured **TTS (Text-to-Speech)** to convert text messages into voice announcements

**Result:** Automated mass notification system actively used in production.

### 🍽 [DineTogether](https://github.com/Gevork23/DineTogether) — Restaurant Table Booking REST API

**Stack:** FastAPI, PostgreSQL, Docker, Celery, Redis, Pytest, JWT

- Built a REST API for restaurant table reservations with role-based access (USER, MANAGER, ADMIN)
- Implemented media file management for cafes and menu items
- Refactored authentication module: removed refresh_token generation to enhance security
- Fixed validation errors and unified error response format for improved frontend integration
- Wrote comprehensive test coverage using **pytest**, reducing regression bugs
- Used **Docker Compose** for local development and deployment

**Result:** Full-featured API service with clean architecture and high test coverage.
